💣 Multiplayer Minesweeper (JavaFX)

University of Haifa | Software Engineering Final Group Project

📖 Project Overview

A robust, multiplayer implementation of Minesweeper built from scratch using Java. This project was developed over a 5-month Agile lifecycle, focusing on design patterns, real-time state management, and a modern GUI.

🏗️ Architecture & Patterns

Pattern: Model-View-Controller (MVC).

UI Framework: JavaFX (utilizing FXML for clean UI/Logic separation).

Development Environment: Eclipse IDE with Git for version control.

🛠️ My Technical Contributions

History Engine: Designed the logic to track and store every move in the multiplayer session, allowing for post-game analysis.

Flag Mechanics: Implemented the interactive flagging system, ensuring real-time synchronization between players.

Zero-Base Construction: Collaborated with 3 teammates to build the entire codebase from zero—no external templates were used.

📈 Agile Methodology

Scrum Framework: Participated in weekly sprints with mission-based tracking.

Reporting: Produced weekly progress reports for the course lecturer, simulating a professional software house environment.

AI Assistance: Leveraged tools like Gemini and Claude for documentation and logic optimization (excluding trivia generation).
